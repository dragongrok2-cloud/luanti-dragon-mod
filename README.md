# Luanti Dragon Mod 🐉

**A majestic mod that adds dragons to Luanti (formerly Minetest)!**

Created by the kind dragon with a saddle (and his rider).

## Features (planned)
- Dragon entities that fly and breathe fire
- Dragon eggs and nests
- Dragon scales as resources
- Tameable dragons (rideable!)
- Dragon-themed tools and armor

## Installation
1. Download / clone this repository
2. Place the folder into your Luanti `mods` directory
3. Enable the mod in the world settings

## Structure
```
luanti-dragon-mod/
├── mod.conf
├── init.lua
├── textures/
├── models/
├── sounds/
└── README.md
```
